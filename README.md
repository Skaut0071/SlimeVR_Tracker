# SlimeVR DIY Project

## Overview
This is a DIY project based on the official SlimeVR documentation. The design is created for educational and hobbyist purposes.

## Project Information
- **KiCad Version:** 9.0
- **PCB Version:** 3W + 2.5WE (older *bigger* board files are saved if you want them *Version 0.7*, *Version 0.9* and *Version 2.5W*)

  > *W:* = Wireless

  > *E:* = Extencion

- **Schematic Version:** 2.0
- **Project Type:** DIY/Hobby
- **Manufacture:** JLCPCB
